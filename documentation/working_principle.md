# Working Principle

## Overview

The PID-based Line Following Robot operates by detecting a predefined path using a five-channel infrared (IR) sensor array and adjusting the speed of two DC motors through a PID control algorithm.

The Arduino continuously reads the sensor values, calculates the position error, and generates correction signals to keep the robot aligned with the line.

The overall operation consists of sensor detection, error calculation, PID control, motor speed adjustment, and line-loss recovery.

## 1. Line Detection

The robot uses a TCRT5000L five-channel IR sensor array to detect the line on the track.

Each sensor detects the reflected infrared light from the surface beneath it. The sensor outputs are connected to the digital pins of the Arduino.

In the implemented program, a LOW digital reading is considered an active line detection.

The five sensor readings are represented as:

$$
S = [S_1, S_2, S_3, S_4, S_5]
$$

where each sensor state is either 0 or 1.

## 2. Error Calculation

To determine the position of the line relative to the center of the robot, a weight is assigned to each sensor.

The weights used in the program are:

$$
W = [-2, -1, 0, 1, 2]
$$

The position error is calculated using the weighted average of the active sensor readings:

$$
E = \frac{\sum_{i=1}^{5} S_i W_i}{\sum_{i=1}^{5} S_i}
$$

Where:

- $E$ = position error
- $S_i$ = state of the $i$-th sensor
- $W_i$ = weight assigned to the $i$-th sensor

A negative error indicates that the detected line is towards the left side, while a positive error indicates that it is towards the right side.

An error of zero indicates that the detected line is centered according to the weighted sensor calculation.

## 3. PID Control Algorithm

The calculated error is supplied to the PID controller, which generates a correction value to adjust the motor speeds.

The PID controller consists of three terms.

### Proportional Term (P)

The proportional term generates a correction based on the current position error:

$$
P = K_p \times E
$$

### Integral Term (I)

The integral term considers the accumulated error over previous control iterations:

$$
I = K_i \times \sum E
$$

To prevent excessive accumulation, the integral value is limited within the range of -50 to +50 in the implementation.

### Derivative Term (D)

The derivative term considers the change in error between consecutive iterations:

$$
D = K_d \times (E - E_{previous})
$$

### Total PID Output

The final PID correction is calculated as:

$$
PID = P + I + D
$$

The PID parameters used in the current implementation are:

| Parameter | Value |
|---|---:|
| Proportional Gain (Kp) | 10.0 |
| Integral Gain (Ki) | 0.9 |
| Derivative Gain (Kd) | 5.0 |

## 4. Motor Speed Control

The PID output is used to adjust the speeds of the left and right motors in opposite directions.

The implementation uses a base speed of 140 and a maximum speed of 200.

The base speed is dynamically adjusted according to the magnitude of the position error. As the error increases, the robot reduces its base speed to improve turning behavior.

The motor speed commands are calculated as:

$$
V_L = V_B + PID
$$

$$
V_R = V_B - PID
$$

Where:

- $V_L$ = left motor speed command
- $V_R$ = right motor speed command
- $V_B$ = dynamically adjusted base speed
- $PID$ = PID correction output

The resulting motor speed commands are constrained between 0 and the maximum speed during normal tracking.

PWM signals generated by the Arduino control the motor speed through the L298N motor driver.

## 5. Line-Loss Detection and Recovery

If all five sensors fail to detect the line, the program identifies a line-loss condition.

In this situation, the robot uses the last known position error to determine the direction of recovery:

- If the last known error is negative, the robot turns left.
- If the last known error is positive, the robot turns right.
- If the last known error is zero, the robot performs a default left-turn recovery.

During recovery, the motors rotate in opposite directions at half of the base speed to help the robot search for the line.

## 6. Overall Working Sequence

The complete working sequence is:

1. The IR sensor array detects the line beneath the robot.
2. The Arduino reads the five digital sensor outputs.
3. Weighted sensor values are used to calculate the position error.
4. The PID controller calculates the required correction.
5. The base speed is adjusted according to the error magnitude.
6. The Arduino generates motor direction and PWM signals.
7. The L298N motor driver controls the two DC motors.
8. If the line is lost, the robot attempts recovery using the last known error.

## Conclusion

The combination of infrared sensing and PID-based motor control enables the robot to follow a predefined path autonomously. By continuously calculating the line-position error and adjusting the relative motor speeds, the system attempts to maintain alignment with the track. The additional line-loss recovery mechanism helps the robot search for the path when the sensors temporarily lose detection.
